# ワークシート デザインガイドライン

「サードエイジ じぶん戦略講座」の **ワークシート（A4横スライド）** 専用デザイン仕様。
ダークアプリUI（[DESIGN_GUIDELINES.md](DESIGN_GUIDELINES.md) のネオングリーン）とは**別系統**。
ワークシートは「白いA4横の紙」を画面で編集し、記入済みをそのままPDF/A4で印刷する。

- 対象: `/workshop/pre/profile-slide`, `/workshop/day1`, `/workshop/homework`, `/workshop/day2`（worksheet track）
- 非対象: 事前/事後アンケート（survey track＝スマホ対応・ダークUIのまま）
- 配布PDF（じぶん戦略講座ワークシート2.pdf）の世界観を踏襲し、HTML/印刷で再現する。

> カラーコードは配布PDFからの**近似値**。正式ブランド色が決まれば微調整する（トークン1箇所を変えれば全体反映できるよう実装する）。

---

## 1. シート寸法・基本

| 項目 | 値 |
|---|---|
| シート | A4横 = **1123 × 794 px**（@96dpi, 297×210mm） |
| 内側余白 | 上下40px / 左右56px（→ 内容幅 約1010px） |
| 紙地 | `#FFFFFF` |
| 1シート = 1ページ | 収まらなければ複数シートに分割（PDFのページ割に縛られず**HTML都合で再配分可**） |
| 実装 | `components/worksheet/PrintSheet.tsx`（既存）＋ `app/globals.css` の `@page A4 landscape` |

| 用途 | トークン名(予定) | 近似値 |
|---|---|---|
| 本文テキスト | `ws-ink` | `#1F2937` |
| 補足・ヒント | `ws-muted` | `#6B7280` |
| 罫線・枠線 | `ws-line` | `#D1D5DB` |
| 薄面（セクション地） | `ws-fill` | `#F4F6F5` |
| **構造アクセント＝ティール**（番号バッジ・区切り・「ルール」ピル・フェーズ表示） | `ws-teal` | `#129B86` |
| **強調＝マゼンタ**（"じぶん" 等キーワード・重要ラベル例「5分以内」） | `ws-accent` | `#E5277E` |
| ルール枠の薄面（ミント） | `ws-mint` | `#EAF3EC` |

## 3. 文字（タイポグラフィ）

- フォント: **Noto Sans JP**（既存 `--font-noto-sans-jp`）
- **日本語のため UPPERCASE / 字間拡張ルールは不採用**（ダークUIとの差別化点）

| 要素 | サイズ | ウェイト | 備考 |
|---|---|---|---|
| シートタイトル(h1) | 26–28px | 700 | キーワード（例「じぶん」）のみ `ws-accent`、他は `ws-ink` |
| 区切り・小見出し | 15–16px | 700 | 必要なら左に `ws-teal` の短線 |
| ラベル | 14px | 600 | 入力欄の見出し |
| 本文 | 14px | 400 | line-height 1.6 |
| ヒント・注記 | 11–12px | 400 | `ws-muted` |
| 番号バッジ内 | 14–16px | 700 | 白文字 / `ws-teal` 塗り円 |

---

## 4. 箱（ボックス）

| 種類 | スタイル |
|---|---|
| 入力欄 | 白地・1px `ws-line`・角丸8px・padding 10–14px。**記入値が印刷に出る**。フォーカス時 `ws-teal` 枠 |
| ルール枠 | `ws-mint` 面・角丸12px・「ルール」アウトラインピル（`ws-teal` 文字＋枠） |
| ヒント吹き出し | 薄グレー面(`#F1F2F4`)・角丸10px・11px `ws-muted`。**印刷で崩れる尻尾は省略**し注記に統一 |
| 図版枠 | **支給画像**を `next/image` で配置。SVG再現はしない |

---

## 5. ライン

- 見出し下の区切り: 1px `#E5E7EB`
- 番号バッジ: `ws-teal` 塗り円＋白文字（①②③…）
- タイムライン: 縦線＋ダイヤ/丸マーカー（生い立ち）
- 手描き風の矢印・コネクタ（PDFのピンク線・黄色▶）は**簡素なCSSコネクタ/アイコンに置換、または図版画像に内包**

## 6. コラム配置（内容幅 約1010px）

12カラム想定の flex/grid。頻出パターン:

1. **ラベル列 + 入力**（左ラベル~120px｜右に入力）― じぶん紹介の会社/部署/役職
2. **2×2 クアドラント** ― 好き得意マトリクス、未来ビジョン
3. **3ボックス横並び** ― 会社とじぶんの一致点、宿題の Reason
4. **フル幅テーブル** ― 分人シェア表
5. **左右対比（現在｜未来）** ― 資本戦略のポートフォリオ/Wish-Can-Shall

## 7. PDF → HTML 翻訳方針（ワークシート個別レイアウトの土台）

配布PDFの見た目とHTML/印刷の作りやすさは異なるため、各ワークは下記方針で「個別に」レイアウトを決める。

1. **図版**（分人主義 individual/dividual、人生の4つのワーク、MVVピラミッド、資本循環図 等）＝**支給画像**。入力部（円・表・箱）＝HTML。
2. **自由配置の吹き出し** → 位置固定の注記スタイルに統一（尻尾は印刷で崩れるため）。
3. **手描き矢印・コネクタ** → 簡素化（CSS/アイコン）または図版画像に内包。
4. **「前ページからコピペ」** → アプリでは**自動引き継ぎ**（保存済みの値を参照表示）。
5. **写真**（じぶん紹介の顔写真）→ アップロード→表示→印刷。
6. **密度の高いPDFページ** → 可読性優先で**複数シートに再分割可**（A4横1枚に詰め込みすぎない）。

各ワークシートを実装する直前に、上記方針に沿って「何枚のシートに、どの図版を画像で、どの入力をHTMLで」を都度確認してから着手する。

## 8. 実装メモ（着手時）

- カラートークンは `tailwind.config.ts` に `ws-*` として追加 → 全シートで参照（ブランド色確定時は1箇所変更で反映）。
- 入力欄プリミティブは `components/worksheet/fields.tsx` を拡張（テキスト/テキストエリア/数値/写真アップロード/2×2/テーブル等）。
- 図版画像は `public/images/worksheets/` に配置。
- 記入値は該当フェーズJSON（pre/day1/homework/day2）へ保存（[lib/workshopData.ts](../lib/workshopData.ts) の浅マージPATCH）。
