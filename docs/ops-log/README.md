# 事務局作業ログ（マニュアル化の素材）

事務局が実際に行った作業を、**あとでマニュアルに起こせる粒度**で記録する。
設計や仕様は [ADMIN_WORKFLOW.md](../ADMIN_WORKFLOW.md)、ここは「実際にやった手順」。

## 書き方

- 1回の作業（1日・1テーマ）につき1ファイル：`YYYY-MM-DD_テーマ.md`
- 手順ごとに次の4点を残す
  - **やったこと**：画面・ボタン名・入力値（個人情報とトークンは伏せる）
  - **どこで**：本番の管理画面か、開発側の操作（スクリプト・DB）か
  - **結果**：画面の表示・届いたメールなど、確認できた事実
  - **マニュアル化メモ**：つまずき・注意点・管理画面に無くて開発が代行した操作
- 「管理画面に無い操作」は、マニュアル化の前に画面を作るか、手順から外すかを決める必要がある。
  各ログの末尾「管理画面に足りないもの」にまとめる
